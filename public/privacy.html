HanYu Cards Privacy Policy

Effective date: June 16, 2026

HanYu Cards is an offline-first Mandarin learning app. Vocabulary progress, review history, daily goal, and settings are stored locally on your device.

Data We Collect

The app does not require an account and does not sell personal data. When you send a message to the AI tutor or request semantic feedback on a mission response, the app sends that text and the minimum relevant vocabulary, progress, or mission context to the configured assistant API so it can answer or evaluate the response.

Data Storage

Learning progress—including daily plans, review history, mistake status, practice statistics, focused study time, and mission scores—is stored in device browser storage or the native app webview storage. Settings lets you export this information to a JSON backup, restore a backup, or permanently reset local progress. Exported backup files are controlled by you and never include the server-side AI API key.

Third Parties

If the AI tutor is enabled, the app backend sends the minimum tutor request and learning context to Agicto, which routes the selected language model. The API key remains on the app backend. Review Agicto's current terms, privacy policy, selected model provider, and deployment region before publishing.
